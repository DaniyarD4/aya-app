# Система

Личный трекер прогресса в стиле «Поднятия уровня в одиночку». Отмечаешь выполненные дела, получаешь опыт, качаешь уровень и характеристики.

Чистые HTML, CSS и JavaScript, без фреймворков, сборки, сервера и внешних запросов. Работает офлайн как приложение на главном экране iPhone.

| Файл | Что это |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `board.js` | доски: бесконечное поле для идей, связанное с квестами, целями и личностями |
| `life.js` | вброс, шаги, «5 минут», время, разбор недели, прогнозы, находки, голоса, быт — всё считается на телефоне |
| `money.js` | денежный автопилот: раскладка поступлений, подушка, копилка хотелок, «Можно купить?», план вместо борьбы |
| `sw.js` | service worker — кэширует файлы для работы без сети |
| `manifest.webmanifest` | название, цвета и иконки для установки как приложения |
| `icons/` | иконки; `icon.svg` — исходник, PNG сделаны из него |

## Приватность

- Данные хранятся только на устройстве, в `localStorage`, и только в зашифрованном виде: AES-GCM-256 через Web Crypto API.
- Ключ выводится из мастер-пароля через PBKDF2-SHA-256: 310 000 итераций, случайная соль 16 байт. На каждое сохранение берётся новый случайный IV.
- Пароль нигде не сохраняется. Забытый пароль восстановить невозможно — можно только стереть данные и начать заново.
- Автоблокировка: через 5 минут бездействия и сразу при сворачивании приложения.
- Content-Security-Policy запрещает странице любые сетевые запросы, внешние скрипты, стили и шрифты.
- `noindex, nofollow` — поисковики страницу не индексируют.

Проверить шифрование: открыть DevTools → Application → Local Storage → ключ `system.vault.v1`. Там лежат только `kdf`, `iv` и шифротекст `ct`.

## Как устроено

- **Квесты.** Название, заметка, тип, одна или несколько характеристик, повтор: разовый, каждый день или каждую неделю. Галочка начисляет опыт, повторная — откатывает его. После отметки есть ещё кнопка «Отменить» во всплывающем окне.
- **Типы и опыт.** Бытовая 10, обычная 25, целевая 60, эпическая 200 XP. Значения меняются в «Настройках».
- **Характеристики.** Опыт квеста делится поровну между выбранными. У каждой характеристики свой уровень: до следующего нужно `100 × уровень^1.5` XP, формула — функция `xpToNext()`. Характеристики можно добавлять, переименовывать и удалять.
- **Уровень и ранг.** Общий уровень считается по той же формуле от всего опыта. Ранг охотника идёт по общему уровню: E с 1, D с 5, C с 10, B с 15, A с 20, S с 30. Пороги меняются в «Настройках». При ~250 XP в день D — примерно через неделю, C — через полтора месяца, S — года через два.
- **Отклик.** При отметке квеста — вспышка, искры, всплывающий «+25 XP», звук и окно «[Квест выполнен]». При повышении уровня — полноэкранное окно LEVEL UP со световым столбом и частицами. За целевой квест — полноэкранное «Достижение получено» с медалью и фанфарой, за эпический — «Босс повержен» с золотой медалью, вспышкой и тряской; в окне можно отменить случайную отметку. При повышении ранга — отдельная сцена: вспышка, ударная волна, старая буква рассыпается, новая влетает в цвете ранга. Звук синтезируется через Web Audio, файлов и запросов нет. Звук и вибрацию можно выключить в «Настройках», там же есть предпросмотр окон.
- **Цели.** Главные направления на экране «Статус» с полосой прогресса. Цель «по этапам» считает долю выполненных квестов-этапов, цель «по числу» — «сейчас / цель» (например, доход в месяц). Квесты привязываются к цели в её окне или в окне квеста. Кнопка «Цель достигнута» даёт опыт эпического квеста и ачивку.
- **Колесо баланса.** Радар по характеристикам на экране «Статус»: длина луча — уровень. «Баланс %» — слабейшая характеристика в процентах от сильнейшей; слабое место подсвечено, по нажатию на точку — подробности.
- **Состояние.** Отдельная вкладка: опоры — обязательные квесты на каждый день или N раз в неделю (сон, тренировки 3 раза в неделю, питание, майндсет, время наедине, проявленность), сфера состояния на сегодня — мыльный пузырь на WebGL: переливы плёнки считаются как интерференция в тонкой плёнке, отражения — из HDR-окружения сцены «bubble burst», по нажатию пузырь лопается брызгами и надувается снова; состояние дня (опоры и сливы) перекрашивает переливы плёнки (мята и бирюза → голубой → янтарь и розовый → красный и фиолет), а ниже 80% пузырь рвётся: дыры с рваными светящимися краями, дрожащий силуэт, срывающиеся капли; скорость переливов — по энергии, линии подписывают, что держит состояние и что тянет вниз. Без WebGL остаётся CSS-сфера, отметки «слива энергии» (снижают состояние, но не опыт), оценка энергии 1–5, график за 7 дней и подсказки, что влияет на энергию. Если опора проседает 2+ дня, на «Статусе» появляется предупреждение.
- **Доски.** Иконка доски в шапке, рядом с шестерёнкой: бесконечное поле, как Miro, но своё и офлайн. Одним пальцем — двигать поле, двумя — масштаб; двойное касание по пустому месту — новый стикер, по элементу — правка текста, долгое нажатие — тоже правка. Стикеры шести цветов, текст, фигуры, круги, рамки (элементы внутри рамки едут вместе с ней), фото (сжимаются до 900 px), стрелки-связи («Связь» → нажать на второй элемент), копия, удаление, изменение размера за уголок, отмена. «В квест» превращает стикер в квест: он попадает в план пилота, к цели доски и заряжает её личность; закрытый квест на доске — с галочкой. Шаблоны: контент-план, цель, мечта, карта мыслей. Время на доске заряжает выбранную личность. Хранится в том же зашифрованном хранилище; на компьютере работают колесо мыши (с Ctrl — масштаб), Delete и Ctrl+Z.
- **Личности.** Шарик во вкладке «Состояние» — это «Я», вокруг него на орбите десять сторон: Стратег, Мечтатель, Образ, Любящий, Тело, Глубокий, Тревожный, Весельчак, Уставший, Воин. У каждой свой заряд: его дают квесты и опоры (кого питает квест, Система угадывает по названию, можно выбрать вручную), блюда дофаминового меню, выгрузка тревоги, сверка баланса и вечерний ритуал; заряд тает вдвое за полтора дня, а Уставшего разряжает работа без отдыха. Кто сейчас «у руля», отмечаешь сам — после вопроса о силах или в карточке личности. Если на откате у руля Воин или Стратег, Система подскажет передать руль тому, кто умеет отдыхать, и предложит, чем его зарядить. В карточке личности можно вписать свои слова о ней — они хранятся зашифрованно. Вид «Опоры» показывает прежние подписи.
- **Дизайн.** Почти чёрный фон, сверху сияние цвета режима: откат — фиолетовое, ровно — синее, волна — бирюзовое; в заголовке «Сейчас» одно слово того же цвета. Кнопки — «меш»: внутри таблетки плывут мягкие пятна цвета под стеклянным бликом; основная — океан (синий с ледяным светом), золотая — мята и сирень, вторичные — тёмные с переливающейся каймой. Голос «Системы» — моноширинные метки в скобках («[ КВЕСТ · ШАГ 1/5 ]»), знак «!» в шапке, острые окна со скобками в моменты событий (квест, уровень, ранг, ачивка). На «Сейчас» — одно дело крупно: шаг, подпись, полоска опыта, «Начать на 5 минут», «Другое дело», «Готово».
- **Экраны.** Внизу четыре вкладки: «Сейчас» (план пилота, что требует внимания — строками, состояние, ранг, вечером — карточка вечера), «Квесты», «Состояние», «Деньги». Ранг, цели, колесо баланса, характеристики и журнал — в «Профиле»: нажми на имя в шапке. Доски и настройки — иконками в шапке.
- **Быстрый вброс.** Строка вверху «Сейчас»: Система сама понимает, что это — квест, трата («такси 2к»), поступление («+150к»), тревога («тревожно из-за…»), идея на доску «Идеи» («идея: …») или отсчёт («выйти в 18:30»). «Изменить» — и она запомнит по первому слову.
- **Шаги.** Тяжёлые и узнаваемые дела (документы, контент, сайт, встреча, учёба, врач, поездка) Система разбивает сама; первый шаг — на 5 минут. В плане — ближайший шаг, галочка закрывает шаг, последний — весь квест. Поправленные шаги запоминаются для таких задач. «5 мин» — таймер «просто начни».
- **Время.** Полоска дня (до вечера, до сна), отсчёт «выйти в…» с напоминаниями за 20 и 5 минут, оценка «сколько займёт» с твоей личной поправкой, инструкция для напоминаний через «Команды».
- **Умнее за счёт твоих данных.** Разбор недели (воскресенье/понедельник): волны, лучший и тяжёлый день, главный слив, вывод и эксперимент. Прогноз отката на завтра с кнопкой «облегчить». «Находки» — связи, подтверждённые днями. Блюда меню — по реальному эффекту на энергию. Вопрос о силах молчит в часы, когда ты обычно отмахиваешься.
- **Личности: руль.** Руль тратит заряд; задачу Воина, сделанную мягкой стороной, Воин получает вполсилы, ведущий — заряжается, Уставший не разряжается. Пустой руль — совет передать. В плане звучит голос того, кто у руля; фразы правятся.
- **Деньги и быт.** Прогноз до конца месяца по темпу трат. Быт по ритму — стирка, уборка, мусор и своё: квест появляется сам, ритм подстраивается.
- **Модули и складки.** В настройках модули выключаются целиком; редкие блоки свёрнуты в строки.
- **Меньше вопросов.** За один вход — не больше одного окна с вопросом: «Как ты сейчас?» вместе с выбором, кто у руля (по желанию), нажатие на цифру сразу всё сохраняет. После квеста — только тихая подсказка «Дальше: …»; окно о силах — если не спрашивали больше 2,5 часа и за этот вход ещё не спрашивали. «Что подтолкнуло?» — только про траты сверх лимита.
- **Пилот энергии.** Под СДВГ силы идут волнами, поэтому вместо расписания — режимы. Система спрашивает «как ты сейчас» (при входе раз в 3 часа и после закрытого квеста), учитывает шарик состояния и выбирает режим: 🌊 Волна, 〰️ Ровно или 🌙 Откат. У каждого квеста есть «вес» по силам (⚡ лёгкий, ⚡⚡ средний, ⚡⚡⚡ тяжёлый — по умолчанию по типу). На «Квестах» план: что сейчас, что потом, сколько по силам сегодня и что ждёт волны; на откате сначала опоры и одно лёгкое, а набрал норму — «на сегодня всё» и подбор отдыха. После квеста — следующий шаг под силы; на долгой волне (2+ часа без перерыва) — напоминание о воде, еде и перерыве. Во вкладке «Состояние» — полоска волн за 14 дней и сколько обычно длятся волна и откат. Выключается в «Настройках».
- **Финансы.** Трата вводится одной строкой («кофе 1500», «такси 2к»): сумма и категория находятся сами по встроенному словарю, незнакомое Система спрашивает и запоминает. Вердикт: ✅ грамотная (необходимое или вклад), ⚠️ спорная (хотелка), ❌ слив (хотелка сверх лимита). Поступления вписываются той же строкой с плюсом («+150к клиент»). Лимиты считаются от реальных денег: поступления за вычетом накоплений минус обязательные платежи (списываются в начале месяца) минус траты — это «свободно сейчас»; лимит дня = свободное / дни до конца месяца, остаток переходит на следующий месяц. Цель «по числу» можно связать с поступлениями месяца. День в лимите или без трат даёт опыт, трата-слив отмечается в сливах энергии. Всё офлайн, без нейросетей и сети. «Настройки» открываются шестерёнкой в шапке.
- **Денежный автопилот.** Включается в «Деньгах». Каждое поступление Система раскладывает сама — «сначала заплати себе»: 🛡 подушка, 🎁 копилка хотелок, ✨ фонд радостей, остальное — на жизнь. Пока доход нестабилен (режим стабилизации), доля зависит от размера поступления относительно месячной нужды (обязательные + обычные траты): маленькое — 10 % в подушку и ничего в хотелки, среднее — 15 % и 5 %, большое — 20 % и 10 %; после подушки-старта 50 000 ₸ — меньше в подушку. Раскладка запоминается в момент поступления. Кошельки виртуальные: Система подсказывает, сколько перевести в копилку банка. Хотелки стоят в очереди: мелочь первой, потом то, что помогает зарабатывать, потом по цене; покупки дороже двух месячных нужд закрыты до стабильного дохода. У каждой — прогноз даты, 48 часов «остывания» и «Купил — без вины» (из копилки, дневной лимит не трогается) или «Передумал» за опыт. «Можно купить?» (кнопка или вброс «можно купить кроссовки 30к?») отвечает ✅ / 🟡 / ⏳ / ❌ с объяснением, «хочу лего 100к» во вбросе кладёт хотелку в очередь. В разборе трат частую хотелку можно «сделать частью плана»: честный недельный лимит, траты в нём — не слив. Когда доход 3 месяца подряд выше нужды и подушка на месяц есть — Система предлагает режим роста (15 % и 15 %, большие хотелки открыты). В разборе недели — деньги: пришло, ушло, отложено, ближайшая хотелка.
- **Разбор трат.** Система ищет хотелки, которые повторяются за 30 дней, и смотрит, когда они случаются: вечером, в дни без сил, рядом с тревогой, сразу после поступлений, когда дома нет еды. На импульсивную трату или трату сверх лимита спрашивает, что подтолкнуло (усталость, стресс, скука, награда себе, голод…). Вместо запрета предлагает замену под причину — заготовку еды, закупку продуктов, ванну или прогулку из дофаминового меню, правило 48 часов — и ставит эксперимент на 7 дней с потолком в половину обычных трат на категорию. Прошёл — опыт целевого квеста и ачивка «Замена работает», не прошёл — разбор заново.
- **Сверка баланса.** Вписываешь, сколько денег реально есть (без накоплений), Система сравнивает с записями. Если меньше — подсказывает, куда могли уйти деньги: категории по привычкам последних 30 дней с примерными суммами, незаписанные обязательные платежи, дни без записей; неразобранный остаток уходит в «Без записи». Если больше — забытое поступление, кэшбэк или корректировка. Напоминание раз в неделю.
- **Продукты.** Квест «Купить продукты» ставится сам раз в N дней (или по кнопке «Холодильник пустой»). Бюджет корзины — доля дневного лимита на дни до следующей закупки, не больше свободных денег. Корзина под набор массы собирается из дешёвых продуктов по максимуму белка и калорий на тенге (норма от веса: белок 1,8 г/кг, 35 ккал/кг); цены правятся под свой магазин. Запись траты «продукты …» закрывает квест сама.
- **Дофаминовое меню.** Кнопка «Мне нужно» внизу экрана: «Я загоняюсь», «Нет сил», «Не могу начать», «Хочу отдохнуть» — Система подбирает одно блюдо из меню (закуски, основные, гарниры, десерты). Десерты (лента, YouTube) стоят золото и идут с таймером; пересидел — отмечается слив. После блюда — «Помогло?», и меню учится предлагать то, что работает.
- **Вечер.** С 19:00 на «Статусе» карточка «Вечер»: ритуал по шагам без выбора, за прохождение — опыт. «Я загоняюсь»: выгрузка мыслей (вернёмся к ним завтра в 12:00), минута дыхания и лёгкое блюдо. Выгруженное потом разбирается: «уже не важно», «сделать квестом» или «ещё подержать».
- **Золото и магазин наград.** 1 🪙 за каждые 5 XP (кроме пролога). Спецпредложения вроде «Шопинг-вечер» и «Набор Лего» покупаются за золото и деньги из фонда радостей — доли поступлений (по умолчанию 5 %), уже вычтенной из лимитов.
- **Статистика.** Вкладка «Журнал»: опыт за сегодня и за текущую неделю (с понедельника), серия дней подряд хотя бы с одним квестом и рекорд серии, график опыта за 7 дней и журнал выполненных квестов по дням со временем и опытом. Если сегодня квест ещё не выполнен, серия не обнуляется до конца дня, а на экране появляется напоминание.
- **Журнал.** Весь опыт считается из журнала выполнений, поэтому откат точный. Удаление квеста или смена настроек не отнимает уже заработанное.

## Бэкап

- **Сохранить:** «Настройки» → «Данные» → «Сохранить бэкап». На телефоне откроется меню «Поделиться» — выберите «Сохранить в Файлы» (можно в iCloud Drive). На компьютере файл просто скачается.
- **Восстановить:** «Восстановить из бэкапа» — в настройках, на экране входа или при первом запуске на новом телефоне. Понадобится пароль, которым бэкап зашифрован. Данные на устройстве заменятся данными из файла, а мастер-паролем станет пароль бэкапа.
- Файл `sistema-backup-ГГГГ-ММ-ДД.json` содержит ту же зашифрованную запись, что и хранилище, плюс дату экспорта. Без пароля он нечитаем.
- Раз в неделю на экране «Статус» появляется напоминание сделать бэкап.

Бэкап — единственная защита от потери телефона или очистки данных Safari. Делайте его регулярно.

## Пролог: прошлые достижения

Чтобы не начинать с нуля, прошлые достижения можно засчитать как выполненные квесты: «Настройки» → «Данные» → «Добавить пролог». Опыт считается по текущим ценам типов задач и сразу поднимает уровень, ранг и характеристики. В журнале такие квесты идут отдельной группой «Пролог». На опыт за сегодня и неделю и на серию дней пролог не влияет. Засчитать его можно один раз.

Файл пролога — обычный JSON, **не зашифрованный**. Не кладите его в репозиторий и удалите после импорта.

```json
{
  "format": "sistema-prologue",
  "v": 1,
  "title": "Пролог",
  "quests": [
    { "title": "Сдал тестовое за день", "note": "FastAPI, Docker", "type": "goal", "stats": ["Интеллект", "Карьера"] }
  ]
}
```

`type` — `chore`, `normal`, `goal` или `epic`. Характеристики сопоставляются по названию; если такой нет, она создаётся. Квест с `"done": false` ещё впереди: он добавится в список активных, а опыт придёт, когда его отметите.

## Размещение

**Вариант А — GitHub Pages (основной для iPhone).** Код может быть публичным: данных в нём нет, они только на устройстве и зашифрованы. Settings → Pages → Deploy from a branch → ветка и папка `/ (root)`. Если репозиторий приватный, Pages для него доступны только на платном плане GitHub; иначе сделайте репозиторий публичным.

Обновление: залейте новые файлы и поменяйте `VERSION` в `sw.js`. При следующем открытии приложение скачает новую версию и предложит перезапуститься.

**Вариант Б — локально, без публикации.** Шифрованию нужен защищённый контекст (`https://` или `localhost`), поэтому двойной клик по файлу не подойдёт. Запустите из папки проекта, например, `python3 -m http.server 8000` и откройте `http://localhost:8000`. Для iPhone этот вариант неудобен: телефону нужен адрес по https.

## Как добавить на главный экран iPhone

1. Открыть адрес приложения в **Safari**.
2. Кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускать с иконки на главном экране.

У приложения на главном экране своё хранилище, отдельное от вкладки Safari. Данные, созданные во вкладке, на иконке не появятся — заводите пароль уже в приложении с главного экрана или перенесите данные бэкапом. После первого запуска с иконки приложение работает без интернета.

Связка ключей iOS может предложить сохранить мастер-пароль. Тогда при входе пароль подставится по Face ID. Решайте сами: это удобно, но пароль окажется в Связке ключей.
