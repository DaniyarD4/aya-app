# Система

Личный трекер прогресса в стиле «Поднятия уровня в одиночку». Отмечаешь выполненные дела, получаешь опыт, качаешь уровень и характеристики.

Чистые HTML, CSS и JavaScript, без фреймворков, сборки, сервера и внешних запросов. Работает офлайн как приложение на главном экране iPhone.

| Файл | Что это |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `sw.js` | service worker — кэширует файлы для работы без сети |
| `manifest.webmanifest` | название, цвета и иконки для установки как приложения |
| `icons/` | иконки; `icon.svg` — исходник, PNG сделаны из него |

## Приватность

- Данные хранятся только на устройстве, в `localStorage`, и только в зашифрованном виде: AES-GCM-256 через Web Crypto API.
- Ключ выводится из мастер-пароля через PBKDF2-SHA-256: 310 000 итераций, случайная соль 16 байт. На каждое сохранение берётся новый случайный IV.
- Пароль нигде не сохраняется. Забытый пароль восстановить невозможно — можно только стереть данные и начать заново.
- Автоблокировка: через 5 минут бездействия и сразу при сворачивании приложения.
- Content-Security-Policy запрещает странице любые сетевые запросы, внешние скрипты, стили и шрифты.
- `noindex, nofollow` — поисковики страницу не индексируют.

Проверить шифрование: открыть DevTools → Application → Local Storage → ключ `system.vault.v1`. Там лежат только `kdf`, `iv` и шифротекст `ct`.

## Как устроено

- **Квесты.** Название, заметка, тип, одна или несколько характеристик, повтор: разовый, каждый день или каждую неделю. Галочка начисляет опыт, повторная — откатывает его. После отметки есть ещё кнопка «Отменить» во всплывающем окне.
- **Типы и опыт.** Бытовая 10, обычная 25, целевая 60, эпическая 200 XP. Значения меняются в «Настройках».
- **Характеристики.** Опыт квеста делится поровну между выбранными. У каждой характеристики свой уровень: до следующего нужно `100 × уровень^1.5` XP, формула — функция `xpToNext()`. Характеристики можно добавлять, переименовывать и удалять.
- **Уровень и ранг.** Общий уровень считается по той же формуле от всего опыта. Ранг охотника идёт по общему уровню: E с 1, D с 5, C с 10, B с 15, A с 20, S с 30. Пороги меняются в «Настройках». При ~250 XP в день D — примерно через неделю, C — через полтора месяца, S — года через два.
- **Отклик.** При отметке квеста — вспышка, искры, всплывающий «+25 XP», звук и окно «[Квест выполнен]». При повышении уровня — полноэкранное окно LEVEL UP со световым столбом и частицами. За целевой квест — полноэкранное «Достижение получено» с медалью и фанфарой, за эпический — «Босс повержен» с золотой медалью, вспышкой и тряской; в окне можно отменить случайную отметку. При повышении ранга — отдельная сцена: вспышка, ударная волна, старая буква рассыпается, новая влетает в цвете ранга. Звук синтезируется через Web Audio, файлов и запросов нет. Звук и вибрацию можно выключить в «Настройках», там же есть предпросмотр окон.
- **Цели.** Главные направления на экране «Статус» с полосой прогресса. Цель «по этапам» считает долю выполненных квестов-этапов, цель «по числу» — «сейчас / цель» (например, доход в месяц). Квесты привязываются к цели в её окне или в окне квеста. Кнопка «Цель достигнута» даёт опыт эпического квеста и ачивку.
- **Колесо баланса.** Радар по характеристикам на экране «Статус»: длина луча — уровень. «Баланс %» — слабейшая характеристика в процентах от сильнейшей; слабое место подсвечено, по нажатию на точку — подробности.
- **Состояние.** Отдельная вкладка: опоры — обязательные квесты на каждый день или N раз в неделю (сон, тренировки 3 раза в неделю, питание, майндсет, время наедине, проявленность), шкала состояния на сегодня, отметки «слива энергии» (снижают состояние, но не опыт), оценка энергии 1–5, график за 7 дней и подсказки, что влияет на энергию. Если опора проседает 2+ дня, на «Статусе» появляется предупреждение.
- **Финансы.** Трата вводится одной строкой («кофе 1500», «такси 2к»): сумма и категория находятся сами по встроенному словарю, незнакомое Система спрашивает и запоминает. Вердикт: ✅ грамотная (необходимое или вклад), ⚠️ спорная (хотелка), ❌ слив (хотелка сверх лимита). Поступления вписываются той же строкой с плюсом («+150к клиент»). Лимиты считаются от реальных денег: поступления за вычетом накоплений минус обязательные платежи (списываются в начале месяца) минус траты — это «свободно сейчас»; лимит дня = свободное / дни до конца месяца, остаток переходит на следующий месяц. Цель «по числу» можно связать с поступлениями месяца. День в лимите или без трат даёт опыт, трата-слив отмечается в сливах энергии. Всё офлайн, без нейросетей и сети. «Настройки» открываются шестерёнкой в шапке.
- **Статистика.** Вкладка «Журнал»: опыт за сегодня и за текущую неделю (с понедельника), серия дней подряд хотя бы с одним квестом и рекорд серии, график опыта за 7 дней и журнал выполненных квестов по дням со временем и опытом. Если сегодня квест ещё не выполнен, серия не обнуляется до конца дня, а на экране появляется напоминание.
- **Журнал.** Весь опыт считается из журнала выполнений, поэтому откат точный. Удаление квеста или смена настроек не отнимает уже заработанное.

## Бэкап

- **Сохранить:** «Настройки» → «Данные» → «Сохранить бэкап». На телефоне откроется меню «Поделиться» — выберите «Сохранить в Файлы» (можно в iCloud Drive). На компьютере файл просто скачается.
- **Восстановить:** «Восстановить из бэкапа» — в настройках, на экране входа или при первом запуске на новом телефоне. Понадобится пароль, которым бэкап зашифрован. Данные на устройстве заменятся данными из файла, а мастер-паролем станет пароль бэкапа.
- Файл `sistema-backup-ГГГГ-ММ-ДД.json` содержит ту же зашифрованную запись, что и хранилище, плюс дату экспорта. Без пароля он нечитаем.
- Раз в неделю на экране «Статус» появляется напоминание сделать бэкап.

Бэкап — единственная защита от потери телефона или очистки данных Safari. Делайте его регулярно.

## Пролог: прошлые достижения

Чтобы не начинать с нуля, прошлые достижения можно засчитать как выполненные квесты: «Настройки» → «Данные» → «Добавить пролог». Опыт считается по текущим ценам типов задач и сразу поднимает уровень, ранг и характеристики. В журнале такие квесты идут отдельной группой «Пролог». На опыт за сегодня и неделю и на серию дней пролог не влияет. Засчитать его можно один раз.

Файл пролога — обычный JSON, **не зашифрованный**. Не кладите его в репозиторий и удалите после импорта.

```json
{
  "format": "sistema-prologue",
  "v": 1,
  "title": "Пролог",
  "quests": [
    { "title": "Сдал тестовое за день", "note": "FastAPI, Docker", "type": "goal", "stats": ["Интеллект", "Карьера"] }
  ]
}
```

`type` — `chore`, `normal`, `goal` или `epic`. Характеристики сопоставляются по названию; если такой нет, она создаётся. Квест с `"done": false` ещё впереди: он добавится в список активных, а опыт придёт, когда его отметите.

## Размещение

**Вариант А — GitHub Pages (основной для iPhone).** Код может быть публичным: данных в нём нет, они только на устройстве и зашифрованы. Settings → Pages → Deploy from a branch → ветка и папка `/ (root)`. Если репозиторий приватный, Pages для него доступны только на платном плане GitHub; иначе сделайте репозиторий публичным.

Обновление: залейте новые файлы и поменяйте `VERSION` в `sw.js`. При следующем открытии приложение скачает новую версию и предложит перезапуститься.

**Вариант Б — локально, без публикации.** Шифрованию нужен защищённый контекст (`https://` или `localhost`), поэтому двойной клик по файлу не подойдёт. Запустите из папки проекта, например, `python3 -m http.server 8000` и откройте `http://localhost:8000`. Для iPhone этот вариант неудобен: телефону нужен адрес по https.

## Как добавить на главный экран iPhone

1. Открыть адрес приложения в **Safari**.
2. Кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускать с иконки на главном экране.

У приложения на главном экране своё хранилище, отдельное от вкладки Safari. Данные, созданные во вкладке, на иконке не появятся — заводите пароль уже в приложении с главного экрана или перенесите данные бэкапом. После первого запуска с иконки приложение работает без интернета.

Связка ключей iOS может предложить сохранить мастер-пароль. Тогда при входе пароль подставится по Face ID. Решайте сами: это удобно, но пароль окажется в Связке ключей.
