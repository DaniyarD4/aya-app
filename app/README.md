# Aya — MVP

Личный ассистент по быту и финансам. Концепция и архитектура — в
[`../docs`](../docs). Рабочее название, легко сменить.

## Запуск

```bash
pnpm install
pnpm dev
```

Открой показанный адрес в браузере. На iPhone — открой в Safari и
«Добавить на экран Домой», чтобы поставить как PWA.

## Что уже работает

- **Ритм** — напоминания по интервалу (раз в N дней) или по дням
  недели, + чек-листы (сезонная подготовка и т.п.).
- **Финансы** — лог трат без единого лимита или запрета, квесты на
  вовлечённость с очками/уровнем, итоги недели по категориям.
- **Сегодня** — дайджест дня.
- **Настройки** — уведомления, экспорт/сброс данных.
- Все данные — локально в IndexedDB на устройстве, без аккаунта.

## Известное ограничение MVP: уведомления

Сейчас напоминания показываются через `Notification()`, пока
приложение открыто (вкладка/PWA активна или свёрнута в фон) — раз в
минуту идёт проверка просроченных/сегодняшних дел. Браузер **не даёт**
запланировать уведомление на будущее, если приложение полностью
закрыто — для этого нужен сервер с Web Push (VAPID-подписка +
крон, шлющий пуши по расписанию). Это следующий шаг, не реализован в
этом проходе — см. `../docs/03-architecture.md`.

## Стек

Vue 3 + TypeScript + Vite + Tailwind v4 + Pinia + vue-router + Dexie
(IndexedDB) + vite-plugin-pwa.

## Структура

```
src/
  features/rhythm/   — напоминания, чек-листы
  features/flow/     — траты, квесты
  design-system/      — переиспользуемые UI-примитивы
  core/               — router, даты, liveQuery-хелпер, settings store
  infra/db.ts         — схема Dexie
  views/              — 4 экрана (роуты)
```
