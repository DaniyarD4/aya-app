# Роадмап (черновой, для обсуждения)

## Фаза 0 — сейчас
Концепция и архитектура (этот набор документов). Разработка не начата.

> **Статус на 2026-09-03:** платформа MVP изменена на веб/PWA (Windows-машина, нет Mac для нативного iOS — см. риски). Фронт Фазы 1 реализован и проверен (Today/Rhythm/Flow/Settings, Dexie-хранилище, PWA-манифест) — код в `../app`. Не хватает бэкенда для web push (напоминания сейчас работают только пока приложение открыто) — следующий шаг.

## Фаза 1 — MVP (личное использование, один пользователь)
Цель: проверить, что сама идея "снимает рутину" реально работает в жизни, до вложений в голос/носимые.
- Rhythm: ручные повторяющиеся напоминания (интервал/расписание/событие) — покупки, готовка, посуда, лекарства, витамины, спортзал. Локальные пуши.
- Сезонные чек-листы — вручную создаваемые на первое время (без погодного API), просто как шаблон-напоминание раз в сезон.
- Flow: логирование трат + простые квесты/награды (без ИИ, без банковской интеграции — ручной ввод).
- Дизайн: премиальный минимализм с первого экрана, даже в MVP — это не то, что откладывается "на потом".
- Без голоса, без LLM-диалога, без носимых устройств.

## Фаза 2 — Ассистент оживает
- Голосовой ассистент, 3 языка, диалоговый слой на LLM.
- Предиктивные напоминания о покупках (на основе истории).
- Сезонные чек-листы — автоматические, по погоде/календарю.
- Финансовая рефлексия через диалог с ассистентом, а не только формы.

## Фаза 3 — Носимые устройства
- Apple Watch companion + HealthKit.
- Контекстные напоминания на основе активности/сна.
- Сторонние браслеты — по спросу/возможности.

## Фаза 4 — Экосистема
- Семейный шеринг (общие списки покупок, общие напоминания).
- Сторонние интеграции: доставка продуктов, аптеки.
- Возможно — открытая платформа/API для сторонних модулей.

## Принцип перехода между фазами
Не начинать следующую фазу, пока предыдущая не используется в реальной жизни хотя бы несколько недель — простота и удобство проверяются использованием, не спецификацией.
