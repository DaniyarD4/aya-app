# Aya — концепция (рабочее название, легко сменить)

## Проблема
Данияр тратит энергию на то, чтобы **помнить** бытовую рутину (еда, посуда, лекарства, витамины, спортзал, сезонная подготовка), вместо того чтобы тратить её на работу. Плюс — импульсивные траты создают фоновую тревогу, но человек **не хочет запретов** — хочет тратить на кофе/одежду/еду свободно, просто осознанно.

## Ценности продукта
1. **Простота** — минимум действий, чтобы что-то настроить или отметить сделанным. Ноль лишних экранов.
2. **Премиальный минимализм фронта** — чисто, спокойно, без визуального шума и геймификационной аляповатости (даже там, где есть геймификация — она сдержанная, не «казино»).
3. **Ноль запретов** — приложение никогда не блокирует и не стыдит за трату. Оно поощряет осознанность, а не ограничение.
4. **Проактивность** — ассистент сам напоминает вовремя, пользователь не должен помнить о том, что нужно проверить приложение.
5. **Голос, а не только текст** — ассистент-девушка, приятный голос, 3 языка (KZ / RU / EN).

## Целевой пользователь (сейчас)
Один пользователь — Данияр. Архитектура должна быть готова к росту (семья/шеринг/экосистема), но **не переусложнять MVP** ради гипотетических будущих пользователей.

## Позиционирование
Не «трекер привычек» и не «бюджет-приложение». Это **личный ассистент по быту**, который снимает когнитивную нагрузку «помнить всё» — во многом ближе к секретарю/помощнику, чем к to-do списку.

## Два столпа функционала (см. [02-features.md](02-features.md))
- **Rhythm** — проактивные напоминания о бытовых циклах (еда, покупки, лекарства, спорт, сезон).
- **Flow** — финансовая осознанность на положительном подкреплении (квесты/награды, не запреты).

Оба модуля объединены одним ассистентом-персоной и одним движком «напомнить в нужный момент, без запретов, без чувства вины».

## Горизонт роста → экосистема
Приложение спроектировано как **ядро + модули**, а не монолит одной фичи — чтобы в будущем можно было добавить: синхронизацию с браслетами/часами, семейный шеринг, сторонние интеграции (доставка, аптека), не переписывая ядро. См. [03-architecture.md](03-architecture.md).
